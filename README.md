# ⌨️ 打字小能手

给 10 岁左右小朋友用的 macOS 入门打字练习工具，原生 Swift + SwiftUI，无第三方依赖。

## 运行

```bash
./build_app.sh            # 生成 build/打字小能手.app
open "build/打字小能手.app"
```

开发调试时也可以直接 `swift run`，或用 Xcode 打开 `Package.swift`。

要求：macOS 14 及以上。

`build_app.sh` 可选环境变量：`VERSION`（版本号，默认取最近的 git 标签）、`BUILD_NUMBER`（默认是提交次数）、`UNIVERSAL=1`（同时编译 Apple 芯片和 Intel）、`ZIP=1`（额外生成 `build/TypingKids-<版本>.zip`）。

## 自动构建（GitHub Actions）

`.github/workflows/build.yml`：

- 推送到 `main`、提 PR、或在 Actions 页面手动运行：自动构建通用版 App，压缩包在该次运行的 **Artifacts** 里下载
- 推送 `v*` 标签（如 `git tag v1.0.1 && git push origin v1.0.1`）：额外自动创建 **Release**，附上压缩包和安装说明
- App 只做了临时签名（没有 Apple 开发者证书），第一次打开需要 **右键 → 打开**

## 功能

- **打字练习区**：
  - **按键练习**：自选键盘区域（基准左手 / 基准右手 / 上排左手 / 上排右手 / 下排左手 / 下排右手，可多选），还可以勾选“包括数字区 / 包括符号区”；快速选择三行：基准键双手、上排双手、下排双手 / 左手全部、右手全部、全键盘 / 包括数字区、包括符号区、清空选择。根据选择自动命名，如「基准键 · 双手」「左手 · 三排全练」「全键盘（含数字和符号）」。选择会记住
  - **词语练习**：跟随系统语言——系统是中文就练拼音词语（看汉字打拼音），否则练英文单词
  - **短句练习**：跟随系统语言——中文系统练拼音短句（日常对话，如“妈妈，我回来了！”），否则练英文短句（练大写和标点）
- **打字游戏区**：
  - 🎈 **字母气球**：按下气球上的字母把它戳破，60 秒一局
  - 🎹 **键盘钢琴**：基准键变成钢琴（A S D F G H J K L ; = 低sol 低la 低si do re mi fa sol la si），照着乐谱弹《小星星》《两只老虎》《欢乐颂》《生日快乐》，歌词逐字跟着走；按错不响、音乐等你；弹完自动完整播放一遍
  - 🫧 **拼音泡泡**：泡泡里是汉字词语，打出拼音戳破；可选显示 / 不显示拼音提示
  - 👻 **打幽灵**：黑夜森林里，左边三只小龙、右边三只小幽灵，幽灵身上有字母，按下字母那一排的小龙就喷火球；打中一次换一个字母，打中 5 次幽灵消失。幽灵越走越快，每按错一次幽灵往前冲一小段，碰到小龙就输，三只全打完就赢，记录最快通关秒数；可选“基准键 / 加上排 / 全部字母”
- **首页底部小贴士**：一次一行，每 4 秒滚动换一条
- **彩色键盘 + 手势演示**：每个手指一种颜色；半透明的双手叠在键盘上，循环演示“手指从基准键伸到目标键 → 按下 → 回到基准键”（大写字母会同时演示另一只手的小指按住 Shift）
- **必须按对才能继续**：打错时那个字母会抖一下、变红，并提示“按成了 X，应该按 Y”
- **百分制评分** = 正确率 60 分 + 速度 40 分
  - 正确率：100% 得满分，60% 及以下得 0 分，中间按比例
  - 速度：以成人正常打字速度为基准（约 40 词/分 ≈ 200 字符/分；按键练习的随机字母较难，基准 160 字符/分），达到基准得满分
  - 90 分以上优秀，75 分以上良好，60 分以上及格；每种练习分别记录最高分
  - 参数集中在 `PracticeSession.swift` 的 `PracticeResult` 和 `Lessons.swift` 的 `benchmarkCPM`，可按需调整
- **字母气球小游戏**：60 秒一局，可选“基准键 / 加上排 / 全部字母”三种范围
- **儿童版音效 + 语音鼓励**：按对是木琴音，连对时音高一级级往上爬像弹旋律；按错是轻柔的“哦哦～”；每连对 10 个有琶音和语音夸奖；连续按错 3 次会语音提醒；练完按分数语音点评（音效全部程序合成）
- **自动切换英文输入法**：进入 App 自动切到 ABC，切走或退出时恢复原来的输入法
- 自动检测大写锁定（caps lock）并提醒；按键直接读取，不受中文输入法影响
- 成绩、星星、最高分自动保存

## 窗口

所有页面按 1280 × 820 的固定画布设计，整体等比缩放到窗口大小，不需要滚动；窗口拖动缩放时保持比例。首次打开时按屏幕大小自动调整窗口。标题栏透明，背景色和窗口融为一体。

## 自然人声

第三方 App 不能直接调用 macOS 的 Siri 自然语音，只能用比较机械的系统语音。所以用 `Scripts/make_voices.swift` 把 `VoiceLines.swift` 里的全部台词（约 140 句）用本机最自然的中文语音预先录成 `.m4a`，**提交在 `Resources/Voices/`**，打包时复制进 App，运行时直接播放，完全离线。`Resources/Voices/voice.txt` 记录录音用的是哪个语音。

- `./build_app.sh` 每次只补录缺少的台词；改了或新增台词后运行一次，再把 `Resources/Voices/` 的变化一起提交
- 换到没有原来那个语音的电脑上：已有录音全部保留，只有缺少的句子用本机语音补录（会有提示）；本机连高品质语音都没有时，缺少的句子运行时改用系统语音
- 想整体换一个声音：`VOICE_ID=<语音标识> ./build_app.sh`（会清空后全部重录）
- 高品质中文语音可在“系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音”下载
- 录音使用的是 Apple 系统语音，适合家庭自用；如果要公开分发，请先确认 Apple 对系统语音生成内容的许可条款

## 家长设置（⌘,）

音效开关、语音鼓励开关、选择鼓励的声音（可试听）、自动切换英文输入法开关、隐藏屏幕键盘（练盲打）、隐藏手指提示、清除成绩。

## 代码结构

```
Sources/TypingKids/
├── App/TypingKidsApp.swift     入口 + 页面切换
├── Model/
│   ├── Keyboard.swift          键盘布局、手指分工、Shift 映射
│   ├── Lessons.swift           练习类别、键盘区域与智能命名、练习内容生成
│   ├── WordBank.swift          英文单词 / 拼音词语 / 短句
│   ├── PracticeSession.swift   练习状态、速度与正确率
│   ├── ProgressStore.swift     成绩保存（UserDefaults）
│   └── BalloonGame.swift       气球游戏逻辑
├── Support/                    按键监听、音效、主题与布局工具
└── Views/                      首页、选择页、练习、键盘与小手、结果、设置；Games/ 下是四个游戏
```

想加内容？在 `WordBank.swift` 里加单词、拼音词语或短句；在 `PianoGame.swift` 里加儿歌（每个音写成基准键字母 + 拍数 + 一个歌词字）。
